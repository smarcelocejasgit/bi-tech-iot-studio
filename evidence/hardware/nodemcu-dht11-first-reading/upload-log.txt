BI-TECH IoT STUDIO — V0.2C PRIMERA ENTRADA FÍSICA: DHT11
LOG DE DEPENDENCIAS, COMPILACIÓN Y UPLOAD (NodeMCU ESP8266 <- D5 / GPIO14 <- DHT11)
================================================================================

Hito registrado:
  DHT11 -> NodeMCU ESP8266 (D5 / GPIO14) -> Arduino C/C++ generado desde Bi-Tech IoT Studio -> lectura real por Monitor Serie

1. DEPENDENCIA INSTALADA Y VERIFICADA
--------------------------------------------------------------------------------
Comando de verificación inicial:
  arduino-cli lib list -> No hay librerías instaladas.

Comando de instalación:
  arduino-cli lib install "DHT sensor library"

Librerías instaladas resultantes:
  - DHT sensor library@1.4.4 (Adafruit)
  - Adafruit Unified Sensor@1.1.12 (dependencia requerida por DHT sensor library)

2. PARÁMETROS DE HARDWARE UTILIZADOS
--------------------------------------------------------------------------------
Placa          : NodeMCU 1.0 (ESP-12E Module)
FQBN           : esp8266:esp8266:nodemcuv2
Puerto USB     : COM15 (Silicon Labs CP210x USB to UART Bridge)
Pin de datos   : D5 -> GPIO14 (DHT_PIN)
Alimentación   : VCC -> 3.3V | GND -> GND
